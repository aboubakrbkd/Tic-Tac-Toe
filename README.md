# Tic Tac Toe Game

This is a simple **Tic Tac Toe** game built with React. It allows two players to take turns and automatically checks for a winner.

## Features
- Two-player Tic Tac Toe game.
- Highlights the winner.
- Built using React with functional components and hooks.

## Installation

To run this project locally, follow these steps:

1. Clone the repository:

   ```bash
   git@github.com:aboubakrbkd/Tic-Tac-Toe.git

2. Navigate to the project directory:

   ```bash
   cd Tic-Tac-Toe

3. Install dependencies:

   ```bash
   npm install
   
4. Start the development server:

   ```bash
   npm run dev
